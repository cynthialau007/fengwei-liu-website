# 刘丰玮 · 个人学术网站

根据《刘丰玮简历【完整版】.docx》制作的中文个人学术网站。纯 HTML、CSS 和 JavaScript，无须安装依赖，电脑与手机均可浏览。

## 预览

直接用浏览器打开本目录下的 `index.html` 即可。也可在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:8765 。退出服务按 Ctrl+C。

## 功能

- 响应式布局、手机折叠导航、页内导航。
- 按研究主题筛选论文、复制完整引用、Google Scholar 论文检索。
- 教育与实践时间线、展开查看更多荣誉与实践经历。
- 邮件联系、复制邮箱与公开版 PDF 简历下载。
- 键盘导航、跳至正文、减少动态效果设置支持。

## 内容与维护

- `index.html`：网站内容、论文条目和链接。
- `styles.css`：色彩、排版、响应式样式。
- `script.js`：菜单、筛选、复制功能；修改论文时同步更新 `citations`。
- `assets/portrait.jpg`：从用户提供的简历提取的肖像。
- `assets/刘丰玮-公开简历.pdf`：重新排版的公开简历。
- `公开简历.html`：公开简历的可打印来源文件；更新后用浏览器另存为 PDF，覆盖上述 PDF。

原始 Word 简历未放入网站。公开版保留姓名、肖像、教育、学术与实践信息及邮箱，省略手机号、出生年月与政治面貌。奖学金列表中重复的学术创新奖仅展示一次。博士毕业时间标为预计。科研项目时间按简历所载项目周期展示，不推断个人实际参与起止时间或项目结项状态。

论文链接为按标题发起的 Google Scholar 检索，不是经过核验的全文或 DOI 链接。网站未提供不存在的论文全文下载。

网站没有第三方字体、分析脚本、外部图像或提交数据的表单。字体采用系统字体；不同设备的字形可能略有差异。点击论文检索或邮件链接时会访问相应外部服务。
